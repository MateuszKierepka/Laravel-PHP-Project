## Overview

The **Laravel-PHP-Project** is a powerful framework designed to streamline the development of modern web applications, combining robust back-end capabilities with a responsive front-end.

### Why Laravel-PHP-Project?

This project aims to simplify the development process while ensuring high-quality applications. The core features include:

- 🎨 **Composer Configuration**: Simplifies dependency management and project setup, ensuring compatibility with PHP and Laravel versions.
- ⚡ **PostCSS Integration**: Enhances styling capabilities with Tailwind CSS and Autoprefixer for modern, responsive designs.
- 🛠 **Artisan Command-Line Interface**: Streamlines development workflows by allowing developers to execute tasks efficiently.
- 🚀 **Vite Build Tool**: Facilitates fast asset management and live reloading, improving the development experience.
- ✅ **Automated Testing with PHPUnit**: Ensures code quality and reliability through organized test suites.
- 🔐 **User Role Management**: Implements role-based access control, enhancing security and user experience.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: PHP  
- **Package Manager**: Composer, Npm

---

### Installation

Build Laravel-PHP-Project from the source and install dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MateuszKierepka/Laravel-PHP-Project
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Laravel-PHP-Project
   ```

3. **Install the dependencies:**

   Using Composer:
   ```bash
   composer install
   ```

   Using npm:
   ```bash
   npm install
   ```

---

### Usage

Run the project with:

Using Composer:
```bash
php artisan serve
```

Using npm:
```bash
npm start
```

---

### Testing

Laravel-PHP-Project uses the **PHPUnit** testing framework. Run the test suite with:

Using Composer:
```bash
vendor/bin/phpunit
```

Using npm:
```bash
npm test
```
